# 08 — 写回编排与命令行

**依赖**：03, 04, 06, 07
**标签**：`type:feature` `risk:medium`

## 做

1. `services/writeback.py`：`run_writeback(...)`
   解析镜像 → 绑定描述文件 → 应用值 → 重算校验和 → 序列化 → 原子落盘。
   - 每一步都要能汇报进度（复用 `JobContext`）
   - **任一步失败即停**，并说清停在哪一步、为什么
   - 落盘前再算一次校验和（先算后写，顺序错了等于白算）
2. CLI：`ads writeback <image> --a2l <描述文件> --values <值集> [--out <路径>]`
   - 默认原地写回；`--out` 写副本
   - 输出改了哪些量、校验和是否更新
   - 退出码：成功 0 / 写回失败 1 / 参数或状态不对 2（与 `ads flash` 保持一致）

## 不做

- 不做交互式确认（命令行由调用方决定）
- 不做备份文件管理（那是版本库的事；原子替换已经保证不留半截）

## 验收

- 端到端：样例 hex + a2l + 值集 → 写回 → 再解析，改的量生效、其余不变
- 校验和随之更新（有规则时）
- 值里有多余/缺失的量时，报出清单但不失败
- 目标不可写 → 报错退出码非 0，且**原文件完好**
- `--out` 不改原文件
