# 02: 配方扩展点

**What to build:** 在冻结的扩展点契约里**新增**一个配方协议，使「适配一个新 ECU = 加一个配方插件」成为可执行的扩展方式，而不是口号。已有协议一律不改；新协议独立成一块，遵循「扩展点只增不改」。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 新增协议，不修改任何已有协议的方法签名
- [ ] 协议描述「给出配方」与「把一步翻译成请求字节」两件事，数据形状用字典 / 领域模型传递
- [ ] 已有插件无需任何改动即可继续工作（回归：`ads plugins` 仍列出 9 个可用插件）
- [ ] 新增能力枚举与协议一致，不存在「只有枚举没有协议」的悬空状态
- [ ] 单测覆盖协议的结构性校验（实现与否、形状对不对）
