# 07: 审计记录

**What to build:** 每次刷写都留一条可长期追溯的记录（时间、操作者、目标、镜像指纹、配方标识、结果、耗时），成功与失败都记，失败带步骤摘要与原因；能按目标与镜像指纹检索。用追加写入、不受日志轮转影响。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 一次作业一条记录，追加写入，进程重启后历史仍在
- [ ] 字段完整：起止时间（UTC）、操作者、目标、镜像指纹、配方标识、结果、耗时
- [ ] 失败也记录，并带失败步骤与原因摘要
- [ ] 可按目标标识检索、可按镜像指纹检索（回答「这个版本刷过哪些台」）
- [ ] 存储格式刻意避开「改字段导致整行错位」的失效模式（不用带表头的表格格式）
- [ ] 写入安全：写到一半中断不会留下半条残缺记录
- [ ] 单测覆盖：成功/失败都留痕、检索结果正确、中断不产生残缺记录
