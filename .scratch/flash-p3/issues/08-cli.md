# 08: 命令行入口

**What to build:** 没有桌面界面时也能用：命令行发起一次刷写并看到逐步进度、查看上次刷到哪断了能不能续、列出历史刷写记录。命令只做薄封装，逻辑全在用例层。

**Blocked by:** 05, 06, 07

**Status:** ready-for-agent

- [ ] 发起刷写：指定目标与镜像，实时输出当前步骤与已传输字节
- [ ] 续刷：能显示上次中断位置与能否续（指纹一致才可续），并执行续刷
- [ ] 历史：能列出历史刷写记录，可按目标过滤
- [ ] 失败时输出具体步骤与可读原因（不是原始字节）
- [ ] 退出码语义明确：成功、失败、拒绝续刷各有区分
- [ ] 端到端测试用仿真网关跑通，断言输出内容而非实现细节
