# 04: 示例配方插件

**What to build:** 一个能跑通完整时序的示例配方插件：把语义步骤翻译成实际请求字节，并把失败响应翻译成人能读的原因（而不是让使用者抱着协议手册查原始字节）。协议专有知识全部留在这个插件里，不进领域核心。

**Blocked by:** 01, 02

**Status:** ready-for-agent

- [ ] 配方按序给出：进入编程会话 → 安全访问 → 擦除 → 按段传输 → 校验 → 复位
- [ ] 每一步能产出对应的请求字节，且字节内容可被逐项断言（不是「发出了东西」就算过）
- [ ] 步骤自带超时、重试次数、是否可取消；擦除与传输中不可取消
- [ ] 否定响应被翻译成可读原因；未知响应保留原始字节，绝不静默当成成功
- [ ] 安全访问的种子—密钥交换顺序正确，能区分「没请求种子」与「密钥错」
- [ ] 校验步骤能给出是否与镜像指纹一致
- [ ] 作为插件被注册表发现，声明的能力正确
- [ ] 单测覆盖：完整序列的字节产出、各类失败的翻译、重试次数上限
