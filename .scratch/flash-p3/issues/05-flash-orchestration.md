# 05: 刷写编排

**What to build:** 一次刷写作业的完整执行：按配方逐步推进、持续汇报进度（当前第几步、已传多少、总共多少）、在不可取消的步骤上挡住取消请求、任一步失败即停下并给出具体原因。用仿真网关驱动，做到在没有硬件的机器上跑通端到端。

**Blocked by:** 03, 04

**Status:** ready-for-agent

- [ ] 一次作业能按配方跑完全部步骤并成功结束
- [ ] 进度事件按约定 topic 推送，数值可核对；相同进度不重复发事件
- [ ] 不可取消步骤期间的取消请求被推迟到该步骤结束，而不是中途中断
- [ ] 可取消步骤能及时停下
- [ ] 任一步失败即整体失败，错误里带：第几步、什么响应、重试了几次
- [ ] 作业声明为可续、且向调度器暴露「已完成到哪」
- [ ] 端到端测试在仿真网关上运行，断言的是进度序列与最终状态，不是内部调用
- [ ] 依赖方向契约仍为 4 kept / 0 broken
