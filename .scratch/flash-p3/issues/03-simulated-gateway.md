# 03: 仿真网关插件

**What to build:** 一个不带任何硬件依赖的网关插件，能按脚本返回响应字节：第 N 次请求返回什么、什么时候超时、什么时候返回否定响应、什么时候假装断连。它让整套刷写流程在没有 CAN 卡、没有 ECU 的机器上也能被完整驱动和验证。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 实现既有网关协议（连接、断开、请求字节、连接状态），签名只传字节与字典
- [ ] 响应可脚本化：按请求序号返回预设响应，超出脚本后有明确行为（不是静默返回空）
- [ ] 能制造异常路径：超时、否定响应、中途断连
- [ ] 会记录自己收到的每一次请求字节，供测试断言「确实发了这些字节」
- [ ] 作为插件被注册表发现，声明的能力正确
- [ ] 单测覆盖：正常收发、超时、断连后请求被拒绝、请求记录可核对
