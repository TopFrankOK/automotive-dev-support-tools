# 01: 刷写领域模型

**What to build:** 刷写域自己的一套数据形状，纯模型、零 IO：目标（ECU 标识、诊断地址、内存布局）、步骤类型（进入编程会话 / 安全访问 / 擦除 / 传输 / 校验 / 复位）、步骤（含超时、重试策略、是否可取消）、配方（有序步骤 + 前置条件）、进度（当前步、已完成段、已传输字节）、审计记录（时间、操作者、目标、镜像指纹、结果）、续刷检查点（完成游标 + 三项指纹 + 擦除是否已做）。它们与标定域、测量域互不感知。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 六类实体齐备，字段含义与规格一致，且不含任何具体协议名或总线名
- [ ] 配方指纹覆盖配方内容与步骤顺序（改顺序也算换配方）
- [ ] 镜像指纹为内容哈希，换文件名不影响
- [ ] 检查点只含游标与指纹，不含镜像数据
- [ ] 单测覆盖：指纹稳定性、步骤不可变、进度推进的边界值
- [ ] 依赖方向契约仍为 4 kept / 0 broken
