# P5 UI（先做能看的：服务层 + 浏览器界面）

## 目标

**让用户能尽快直接点着看**，核对需求是否符合。
所以本期只做「本地单机、浏览器可用的界面」——不碰 Tauri（cargo 未安装），
不碰 MATLAB 桥（进程外，优先级低）。

## 范围

做：FastAPI 服务层（`apps/api`）+ 无构建的前端（原生 HTML / JS / CSS）
跳过：Tauri 壳、MATLAB 桥

## 边界（必须守住）

- **逻辑全在 `services`**：`apps/api` 只做参数校验、调用与序列化 —— 与 CLI 同一条规矩。
  桌面壳将来打交道的也是这一层，所以路由按「一次用例一个端点」设计，
  不把内部模型直接漏出去。
- **前端不做构建**：改完刷新就能看，不引入 node 工具链。
- **文件浏览限制在配置根目录下**，不暴露任意路径。
- **无鉴权**：只监听 `127.0.0.1`，不对局域网开放。

## 界面（一页，五个 tab）

| Tab | 做什么 | 用哪个 service |
|---|---|---|
| 插件 | 看有哪些插件可用 | registry |
| 标定比对 | 选两份数据 → 差异表 + Excel 报告 | `run_compare` |
| 测量数据 | 选文件 + 信号 → 趋势折线（SVG） | `extract_trend` |
| 写回 | 选 image / a2l / 值集 → 写回，报告改了哪些量 | `run_writeback` |
| 刷写 | 历史记录 + 发起一次刷写 | `run_flash` / `AuditLog` |
